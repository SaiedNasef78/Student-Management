# Student Management System

A C# Windows Forms application for managing student information and displaying student ID cards.

## Features
- Add and display student information.
- Delete student records.
- View student ID cards.
- Display student details and profile images.
- Clear input fields and refresh the ID card.

## Technologies
- C#
- .NET Windows Forms
- Visual Studio

## Main Classes
- Form1: Manages student records and ID card data.
- frmPrintCard: Displays student information in a separate ID card form.

## How to Run
1. Open the project in Visual Studio.
2. Build the solution.
3. Run the application.

## Note
Student records are stored temporarily and are not saved to a database.
